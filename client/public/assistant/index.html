V1 · Society assistant

An assistant that learns how you live.

GurgaonFlat is building a personal AI agent for commuters, starting with people moving to cities like Gurgaon. On Claude, the agent builds a persistent understanding of each user’s workplace, budget, commute, lifestyle, and preferences, then researches fragmented local information to help them decide where to rent, which society fits best, and how to navigate the city. This page is the working v1: it saves that context on your device, reads the latest society index, and returns a short list fitted to you.

How you’re building

Claude is the core intelligence layer.

We are building toward an AI-native local operating system where every person has an agent that understands their city and proactively helps them make better decisions about where and how they live. The society assistant deeply understands each place, continuously researches and updates local information, remembers context, and gives highly personalized recommendations to people deciding where to live in Gurgaon.

V1 already does the local half in the open: your profile is remembered in this browser, recommendations are recomputed from the live GurgaonFlat society index (rankings, area, price, and BHK), and each result explains why it fits. Claude is how that layer becomes an agent that keeps researching the city, not a one-off form.
